# המסע הראשון שלי באנגלית

משחק דפדפן אינסופי לילדי כיתה ב׳ שמתחילים ללמוד אנגלית מאפס.

## העלאה ל-GitHub Pages

1. צרו מאגר חדש ב-GitHub.
2. פתחו את המאגר ובחרו `Add file` ואז `Upload files`.
3. העלו את כל הקבצים והתיקיות שנמצאים לצד קובץ זה. חשוב לשמור את תיקיית `assets` ואת המבנה שלה.
4. לחצו `Commit changes`.
5. עברו אל `Settings`, אחר כך `Pages`.
6. תחת `Build and deployment`, בחרו `Deploy from a branch`.
7. בחרו את הענף `main` ואת התיקייה `/ (root)`, ואז לחצו `Save`.
8. לאחר כמה דקות יופיע קישור לאתר.

האתר אינו דורש שרת, מסד נתונים או חשבון לילדים. ההתקדמות נשמרת מקומית בדפדפן.
